Privacy Notice

This notice explains what information is processed when you use Roof & Solar Toolkit. The site provides homeowner planning calculators and guides for the United States. It does not offer account registration, quote requests or a site-hosted contact form. It is not currently displaying advertising.

Calculators and information you enter

The roof-area, roof-replacement and standard solar-savings calculations run in your browser. Their calculator inputs are not sent to the site's calculation APIs. If you use the city-based solar production or nearby utility-rate features, the location and model inputs needed for those requests are sent to this site's Cloudflare-hosted services and, where applicable, to the named data providers described below.

City and state lookup

If you use the location search, the city or place name and state abbreviation are sent to a server endpoint hosted with Cloudflare and checked against the U.S. Census Bureau's TIGERweb service. The returned coordinate represents a Census place; it is not your street address, parcel, roof location or utility service territory. Search suggestions may be cached briefly. Exact lookup responses are not cached by this site.

Solar production estimates

If you request a solar production estimate, the selected Census representative latitude and longitude and the system assumptions you enter (system capacity, tilt, azimuth and losses) are sent through this site's Cloudflare-hosted endpoint to the National Laboratory of the Rockies (NLR) PVWatts V8 service. The request uses a server-side API credential; that credential is not sent to your browser. The feature does not ask for your street address, utility account credentials, electricity bill, annual household usage or installer quote.

Nearby utility-rate search

If you request nearby utility-rate records, the selected Census representative latitude and longitude are sent through this site's Cloudflare-hosted endpoint to the OpenEI Utility Rate Database. Returned records are possible matches only. They do not confirm which utility serves your property or establish your current tariff, import rate, export credit or eligibility.

Request limits and technical operation

The site uses Cloudflare services to host, secure and operate its pages and API endpoints. It keeps aggregate request counts to help prevent abuse and enforce shared usage limits; these counters do not contain calculator inputs, place names or visitor IP addresses. Cloudflare may process connection and request information, such as IP address, browser and request metadata, to deliver and protect the website under its own service terms and privacy practices.

Website performance analytics

The domain and Pages project are configured for Cloudflare Web Analytics. Cloudflare describes this service as collecting browser performance timing metrics, such as page-load and Core Web Vitals measurements, and states that it does not collect or use visitors' personal data or track individual end users across customers' Internet properties. Cloudflare's Web Analytics documentation is available at About Web Analytics and Data origin and collection. Cloudflare also provides network and security services for this domain; those services are separate from the browser performance metrics described here.

Advertising

This site is not currently displaying Google AdSense ads and does not currently load an AdSense ad-serving script. If advertising is introduced, this notice will be updated to explain the relevant advertising technologies, data use and available choices before ad serving is enabled.

External links

This site links to government agencies, technical documentation, Census, PVWatts, OpenEI and other providers. Their own privacy notices and practices apply when you visit those services.

Contact and privacy requests

For questions about this notice or privacy-related requests, email getroofsolarcalculator@gmail.com. Do not send passwords, utility account credentials, unredacted bills or other sensitive personal information. Include only the information needed to describe your request.

Your choices

You can choose not to use the location-based solar and utility-rate features. The other browser-based calculators remain available. You can also use browser controls to manage site data and network requests, although blocking required scripts or requests may prevent some features from working.

Changes to this notice

This notice will be revised when the site's data flows or services materially change. The date above identifies the latest published revision.
