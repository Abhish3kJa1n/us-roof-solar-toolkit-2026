Estimated module count
Ready to calculate

Enter annual usage, target offset, modeled production and module wattage—or use a quoted system size as the alternative method.

The estimate is arithmetic, not a roof layout or final system design. Shading, orientation, setbacks, fire access, obstructions, structural capacity, equipment compatibility, local code and actual installation design can change the usable count. Do not treat module area as the roof area required.

How the panel-count estimate works

The usage-based method first multiplies annual household electricity use by the target generation-offset percentage. It divides that target annual generation by the modeled annual kWh produced per DC kW to estimate array capacity. The array capacity is then converted to a whole number of modules using the nameplate wattage of each panel, rounding up so the module count meets or exceeds the requested modeled capacity.

In formula form: target annual generation = annual electricity use × target offset. Estimated array size (kW DC) = target annual generation ÷ annual production (kWh per kW DC). Panel count = array size × 1,000 ÷ module watts, rounded up to a whole module.

Get a production assumption that matches the location

Solar production varies with location, weather data, array tilt, azimuth, shading, system losses and equipment. The city solar production estimator uses a Census representative place point and the PVWatts model to provide a typical-year production estimate. A city point is not your home address and does not capture trees, roof obstructions, micro-shading or the exact roof plane. A proposal's site-specific production model may be more relevant if its assumptions are documented and credible.

A generation offset does not equal the same bill reduction

Solar electricity used directly in the home can displace some grid purchases. Surplus generation may be exported at a different rate under the utility's tariff. Fixed charges, minimum bills, time-of-use periods, demand charges, taxes and export rules can prevent a modeled 100% annual generation offset from eliminating the electric bill. Use the solar savings calculator to model separate import and export values with your own tariff assumptions.

Panel count is not a roof-fit calculation

The simple sum of panel surface areas excludes gaps, roof edges, required fire pathways, access space, vents, chimneys, skylights, dormers and unusable roof planes. A qualified installer must assess roof layout, structural condition, attachment method, electrical design and local requirements. Do not infer that all unshaded roof area is available for modules.

What to check in a solar proposal

  • Module manufacturer, model, wattage, dimensions and product warranty.
  • DC nameplate capacity, inverter type and AC rating.
  • Annual production estimate, weather dataset, shading assumptions and modeled losses.
  • Roof layout, setbacks, attachment details and structural review.
  • Cash price, financing fees, loan terms, lease/PPA escalators and service responsibilities.
