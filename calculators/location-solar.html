Step 2 · PV system assumptions

Describe the solar array

These are editable model assumptions, not facts inferred from your city. The starting scenario uses a 1 kW DC reference system, 20° tilt, south-facing azimuth and 14% losses so the result can be read as kWh per kW DC. Replace these values with a proposal or roof-plane assumptions when known.

The 1 kW starting value is a reference configuration for per-kW yield, not a recommended home system size. Residential scope limit: 100 kW DC.

How to read the estimate

The city lookup supplies a representative Census place point. PVWatts models production from that point and the array assumptions you enter; it does not assess an individual roof, nearby shade or a home's electrical system.

Production is not bill savings

The value of solar electricity depends on when it is used, the utility's import rate, export compensation and other tariff rules. This tool estimates production only. Use your own bill and current utility tariff for a savings calculation.

Data sources and methodology

Location: US Census Bureau TIGERweb place geography. The selected point represents a Census place, not a home or utility service boundary. Census TIGERweb.

Solar production: National Laboratory of the Rockies (NLR) PVWatts V8 uses system inputs and typical meteorological-year solar resource data where available. It is a modeled estimate, not live weather or a roof inspection. PVWatts V8 API documentation.

Utility-rate lookup: Nearby records are drawn from the OpenEI Utility Rate Database. A nearby record may belong to a different utility or rate plan; confirm it against your bill and the utility's current tariff. OpenEI rate-data documentation.
